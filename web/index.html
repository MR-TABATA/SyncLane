題名を編集

この題名は、会話の中の、この話題のまとまりにだけ付きます（前の発言と 30 分以上あいた位置、または「続きから」の再開から、次のまとまりが始まります）。空にして保存すると、会話全体の題名に戻ります。

トークン使用量

Claude Code・Codex・Gemini CLI の記録から集計しています。Antigravity・Web 版の Gemini と ChatGPT は、まだ集計していません（含まれません）。費用（金額）は、計算しません。

この話題を Markdown でコピー

この話題の、あなたと AI の発言と、実行したコマンド・触ったファイルを書き出します。ツールの実行結果と、AI の思考は、保存していないので、含まれません。

選んだ依頼文が、書き出しの先頭に入ります。貼り付けるだけで、別の AI に頼めます（SyncLane は、AI を呼びません）。

Claude Code に登録するコマンド
Claude アプリ（デスクトップ）の設定

設定 → 開発者 → 「設定を編集」で開く claude_desktop_config.json に書き足し、Claude アプリを完全に終了して起動し直します。

登録すると、その AI は保存した全会話を読めるようになります。会話の中にパスワードやコードが含まれていないか、確認してから登録してください。通信は PC の中だけで、ネットワークには出ません。読み取り専用です。

アプリを別の場所に移したときは、登録し直してください。

サーバーに送る会話は、API キー・トークン・パスワードなど、秘密に見えるものを伏せてから送ります。手元の記録と検索は、元のままです。迷ったら伏せる側に倒しているので、秘密でないものを伏せることもあります。

必ず伏せる語

社内だけの名前（ホスト名・顧客名・案件のコード名など）。1 行に 1 つ。そのままの文字列として探します（大文字小文字は区別）。「re:」で始まる行は正規表現です。

伏せなくてよい値

1 行に 1 つ。値が完全に一致したときだけ、そのまま送ります。ここに書いた値は、外に出ます。
