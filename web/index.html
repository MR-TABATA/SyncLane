Claude Code などの AI が、保存した過去の会話を検索できるようにします。AI に「前にどう決めたっけ」と聞くと、SyncLane から探して答えます。

Claude Code に登録するコマンド
Claude アプリ（デスクトップ）の設定

設定 → 開発者 → 「設定を編集」で開く claude_desktop_config.json に書き足し、Claude アプリを完全に終了して起動し直します。

登録すると、その AI は保存した全会話を読めるようになります。会話の中にパスワードやコードが含まれていないか、確認してから登録してください。通信は PC の中だけで、ネットワークには出ません。読み取り専用です。

アプリを別の場所に移したときは、登録し直してください。
