# SyncLane for AI chats — Privacy Policy / プライバシーポリシー

Last updated / 最終更新: 2026-10-19

## English

SyncLane for AI chats is a browser extension that works together with the SyncLane macOS app.

**What it reads.** On gemini.google.com and chatgpt.com, it reads the conversation shown on the page (your messages and the AI's text replies).

**Where it sends it.** Only to the SyncLane app running on the same computer, at `http://127.0.0.1:47821`. It does not send anything to the developer, to any server on the internet, or to any third party.

**What it does not do.** It has no account, no analytics, no advertising, and no tracking. It does not sell or share data. It does not use remote code.

**What it stores.** The extension itself stores nothing. The conversation is saved by the SyncLane app, in a database on your own Mac. If the app is not running, the extension keeps the conversation in memory only until the page is closed, and sends it again when the app starts.

**Your control.** Remove the extension in Chrome (chrome://extensions) to stop everything. Delete the conversations in the SyncLane app to remove saved data.

Contact: https://github.com/MR-TABATA/SyncLane/issues

## 日本語

SyncLane for AI chats は、macOS アプリ「SyncLane」と一緒に使うブラウザ拡張です。

**読み取るもの。** gemini.google.com と chatgpt.com で、画面に表示されている会話(あなたの入力と、AI のテキストの応答)を読み取ります。

**送り先。** 同じコンピュータで動いている SyncLane アプリ(`http://127.0.0.1:47821`)だけです。開発者にも、インターネット上のサーバーにも、第三者にも、何も送りません。

**しないこと。** アカウント、アクセス解析、広告、追跡はありません。データの販売・共有もしません。リモートコードも使いません。

**保存。** 拡張自体は何も保存しません。会話を保存するのは SyncLane アプリで、保存先はあなたの Mac の中のデータベースです。アプリが起動していないときは、ページを閉じるまでの間だけメモリに持ち、アプリが起動したら送り直します。

**あなたの操作。** Chrome(chrome://extensions)で拡張を削除すれば、すべて止まります。保存したデータは、SyncLane アプリで会話を削除すると消えます。

連絡先: https://github.com/MR-TABATA/SyncLane/issues
